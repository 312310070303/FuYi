# 浮译 · 使用说明

> 一个悬浮在游戏上方的日文截屏翻译工具。点悬浮球 → 冻结画面 → 框选或点选日文 → 中文译文直接弹在游戏上方，不用切应用。
>
> 适用：Android 11+（小米 MIUI / HyperOS），需要联网调用翻译 API。

---

## 一、安装

1. 把 `浮译_v1.1.apk` 传到手机（微信文件传输助手 / 数据线 / 网盘均可）。
2. 在手机上点开 APK，选择「安装」。
3. 如果提示「未知来源」，按提示允许本次安装。
4. 安装完成后打开「浮译」。

---

## 二、首次配置（约 2 分钟）

### 1. 给权限

| 权限 | 操作 |
|---|---|
| 悬浮窗 | 点「授予悬浮窗权限」→ 打开「显示悬浮窗」 |
| 无障碍 | 点「开启无障碍服务」→ 设置 → 更多设置 → 无障碍 → 已下载的应用 → 浮译 → 开启 |
| 通知 | 首次打开会弹，允许即可（用于常驻通知，防止后台被杀） |

开完无障碍后，回到 App 点「测试截屏」：
- 能看到游戏画面 → 正常；
- 全黑 → 该界面禁止截屏（登录/支付页常见），游戏内一般不受影响。

### 2. 填翻译 API

App 支持任何 **OpenAI 兼容**接口（`/chat/completions`）。点上方预设可一键填入地址和模型：

| 预设 | API 地址 | 模型 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` | `gemini-2.0-flash` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |

填好后点「测试连接」，出现 `✅ ...` 即成功。

> 也可以填任何自建/中转的 OpenAI 兼容地址（如 one-api、new-api）。

### 3. 小米必做设置（很重要）

小米会杀后台、限制悬浮窗，不做这几步可能点几下就失效：

1. 设置 → 应用设置 → 应用管理 → 浮译 → 权限管理：
   - **显示悬浮窗**：允许
   - **后台弹出界面**：允许
2. 应用信息 → **省电策略**：无限制
3. 应用信息 → **自启动**：允许
4. 最近任务（多任务界面）→ 下拉浮译卡片 → **锁定**
5. 游戏加速（Game Turbo）→ 把浮译加入白名单，或关闭「防打扰」

### 4. 启动

回到 App，点「启动悬浮球」。首次会弹通知「浮译运行中」，属正常。然后切回游戏。

## 三、日常使用

1. 游戏里点一下右侧的「译」字悬浮球（球会短暂隐藏）。
2. 画面冻结并压暗，约半秒后日文文字块会被细框标出。
3. 两种操作任选：
   - **点**某个文字框 → 直接翻译这一块；
   - **拖**一个矩形 → 只识别框内文字。
4. 约 1 秒后，译文卡片从选区旁边弹出：上面小字是原文，下面大字是译文。
5. 卡片按钮：
   - **复制**：复制译文；
   - **重译**：重新请求一次（网络抖动时用）；
   - **关闭**：关闭卡片，悬浮球恢复。
   - 按住卡片上半部分可以拖动位置。
6. 想取消选区：按返回键，或点右上角「×」。

### 术语表

设置页第③块，每行一条 `原文=译文`，例如：

```
勇者=勇者
魔導士=魔导师
ギルド=公会
```

翻译时会带给模型，保证人名、技能名前后一致，最多 200 条。

## 四、常见问题

| 现象 | 原因 / 解决 |
|---|---|
| 点悬浮球没反应 | 无障碍被系统关了。回 App 看「无障碍服务」是否 ✅，重新开启 |
| 提示「截屏失败」 | 无障碍失效或截屏太频繁，隔 1 秒再点 |
| 截出来全黑 | 该界面启用了 FLAG_SECURE（登录/支付/部分过场），无解，换界面即可 |
| 悬浮球不见了 | 后台被杀。下拉通知栏点「浮译运行中」，或重开 App 启动 |
| 翻译报 401 | API Key 错或过期 |
| 翻译报 402 / 余额不足 | 去服务商充值 |
| 翻译超时 | 游戏加速器/VPN 把 API 也代理了；在加速器里把 API 域名设为直连，或翻译时关代理 |
| 识别不到文字 | 字体太花或背景太杂；把框拉大一点，或只框对话框 |
| 译文挡住画面 | 拖动卡片挪开；或点关闭 |
| 游戏变卡 | 只在点球时截一帧，正常不影响；若持续卡，检查是否开了连点/录屏类软件 |

## 五、隐私与费用

- **截图不出手机**：截屏只在本地做 OCR，上传给翻译 API 的只有识别出来的日文文本。
- **Key 只存本机**：保存在 App 私有目录，不会上传到任何第三方（除了你填的 API 服务商）。
- **费用**：按你选的 API 计费。一般一句游戏台词几分钱，一局游戏约 ¥1–6。
- **不建议**在 PvP / 排位场景使用：虽然只读屏幕、不注入游戏，但少数反作弊会检测悬浮窗/无障碍，保守起见剧情和 PvE 用。

---

## 六、卸载

设置 → 应用管理 → 浮译 → 卸载。卸载前建议先在 App 里点「停止悬浮球」，并在无障碍设置里关闭服务。
